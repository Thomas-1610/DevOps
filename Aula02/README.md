
## 1. Instalação e Preparação do Ambiente
- Baixar e instalar o Visual Studio Code.
- Criar uma pasta local para o projeto.
- Abrir a pasta no Visual Studio Code.

## 2. Criação dos Arquivos do Projeto
- Criar o arquivo index.html na pasta raiz.
- Criar o arquivo style.css na mesma pasta.
- Criar o arquivo script.js na mesma pasta.
- Inserir e salvar os códigos correspondentes em cada arquivo.

## 3. Configuração do Git e Integração com o GitHub
- Inicializar o repositório Git local.
- Configurar usuário e e-mail no Git.
- Criar um novo repositório no GitHub.
- Vincular o repositório local ao remoto.

## 4. Publicação Inicial do Código
- Adicionar os arquivos à área de staging.
- Realizar o commit inicial.
- Enviar o código para o repositório remoto.

## 5. Modificação e Versionamento
- Realizar alterações nos arquivos do projeto.
- Adicionar e comitar as alterações.
- Criar uma tag de versão.
- Enviar as alterações e tags para o GitHub.
